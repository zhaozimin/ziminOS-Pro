# 微信快捷收集

这条入口只有一个落点：**《兼收并蓄》里的 `灵感集.md`**。

执行一律调用 `notectl.py`（安装后在 `系统根/.ziminos/skills/scripts/notectl.py`）。**禁止手写文件、禁止用 Edit 直接改笔记、禁止管道灌 JSON、禁止 heredoc。** 内容含引号或换行时用 `--content-file <绝对路径>`。

目标路径、清洗、链接搬运与插入位置都是同输入同结果的活儿，必须交给脚本。用户原话不润色、不总结、不补主语、不改措辞、不加标签。

---

## 1. 先判断该不该收，不再判断收去哪

| 用户在做什么 | 动作 |
| --- | --- |
| 明确要求记录、收藏、保存到 Obsidian | 写入灵感集 |
| 发来一条需要保存的链接、分享卡片、转发文字或长内容 | 写入灵感集 |
| 说「今天发生了……」「写进日记」但这条消息来自微信快捷收集 | 仍写入灵感集 |
| 要求你执行任务、回答问题、检索资料，没有保存意图 | 不写 |

**不再区分灵感、剪藏与日记。** 微信发给 Agent 的内容只要需要保存，就统一进入灵感集；分类和消化是回到 Obsidian 之后的事，不在收集入口抢着做。

`剪藏/` 是浏览器剪藏插件的独占落点。无论消息多长、是不是整篇文章、是不是转发正文，Agent 都不得写进 `剪藏/`，也不得调用 `clip`。

这条 Skill 同样不往《以人为本》的日记或《赛博永生》写。用户若不是在做微信快捷收集，而是在另一个明确工作流里维护日记或知识，交给对应工作流处理，不借本 Skill 绕过去。

---

## 2. 写入

先跑一次 `status` 确认三本库都在，再写。`status` 报错就照实说明，不要自己猜库的位置。

```bash
python3 ~/…/.ziminos/skills/scripts/notectl.py status
python3 ~/…/.ziminos/skills/scripts/notectl.py inspiration --content "定价页把年付放在最前面"
```

内容含换行、引号、反引号或 shell 符号时，先把用户原话原样放进临时文件，再传绝对路径：

```bash
python3 ~/…/.ziminos/skills/scripts/notectl.py inspiration --content-file /tmp/ziminos-capture.txt
```

临时文件只用来安全传参，写入结束后删除。不要把内容插进命令字符串；一句话里出现 `$()` 或反引号时，那会把原话误当 shell 执行。

### 带链接的时候

原样把地址交给脚本，不要自己排版。脚本会决定它是搬到下一行的子项还是就地包成 Markdown 链接。

不要访问地址取标题，不要生成摘要。快捷收集保存的是用户此刻交回来的原件，不是 Agent 看过之后的二手转述。

### 一条消息就是一笔

同一条微信消息默认作为一笔写入，不因内容里有几个句号就擅自拆开。只有用户明确说「分别记两条」时才执行两次写入；两次都要各自成功，回执也各占一行。

---

## 3. 原话保留是红线

不润色、不总结、不改措辞、不替他补主语、不加标签。脚本只做它已有的确定性安全处理与链接排版，Agent 不在调用前加工内容。

尤其禁止：

- 把转发正文概括成一句“核心观点”；
- 给灵感补一个看似更专业的标题；
- 看到人名就自行加 `[[双链]]`——人物档案在隔壁库，跨库双链是死链；
- 因为内容很长而改投 `剪藏/`；
- 因为内容写的是今天而改投日记。

---

## 4. 回执

成功时原样输出脚本的 `display`，没有异常就只说这一行：

```text
✓ 已记进灵感集 · 灵感集.md
```

禁止复述用户刚说过的话、汇报调用了哪个脚本、解释为什么没有进剪藏、写「已为您成功记录」之类客套话，或在成功后追问「还需要我做什么」。

---

## 5. 失败分级

| 退出码 | 含义 | 该怎么说 |
| --- | --- | --- |
| 2 | 明确未写入 | 照实说没写进去，并转达脚本原因；可以修正后重来 |
| 3 | 结果未知 | **禁止重试**。重试可能把同一条写两遍，请用户打开灵感集确认 |

常见退出码 2：

- 「系统根不存在」/「没找到任何一本装了版次标记的笔记库」：用 `--root` 指出系统根；仍失败就如实说明。
- 「超过单条上限」：说明这条太长，没有改投剪藏；请用户决定是否拆成几笔。

---

## 6. 边界

- 只写 `兼收并蓄/灵感集.md`，命令不接受任意目标路径。
- 不写 `兼收并蓄/剪藏/`；那是浏览器插件的地盘。
- 不写《以人为本》的日记、人脉、客户、项目或读书笔记。
- 不写《赛博永生》。
- 不做笔记检索、整理、摘要与知识提炼。
- 不主动记录、不扫描、不定时任务；每一笔都由用户在微信里明确触发。
