# 赛博永生

这是你的**成品库**。

你做完一个项目、点了归档，它会被拷一份进来。然后机器把它编译成一张互相引用的知识网——概念、人物、结论各自成页，彼此链接，越长越密。

你在这里不写字。你在这里**提问**和**验收**。

## 三层结构

| 目录 | 是什么 |
| --- | --- |
| `10-raw/` | **原料层。** 从《以人为本》搬来的已完成项目副本，只读——谁都不许改，包括机器 |
| `20-wiki/` | **知识层。** 机器编译出来的概念页、实体页、结论页。你也可以改，改了不会被覆盖 |
| `90-system/log.md` | **账本。** 每次消化、提问、体检都记一行，只追加 |
| `CLAUDE.md` | **宪法。** 机器在这本库里的全部工作规则。想调整它的干活方式，改这一篇 |

**原料为什么只读？** 因为它是这本库唯一的事实源。wiki 里的每一句话最终都要能追回某份原料的某一段——原料一旦能被改写，「这句话是从哪来的」就再也答不清楚了。而答不清楚的知识库比没有更糟：它看上去有依据。

## 三件你能让它做的事

### 一、消化

> 把新搬进来的都提炼了

它会读一份原料，然后**同时更新十几页**——不是写一篇读后感。一个项目里既有概念、也有人、也有结论，各自该落在各自的页上，并且互相链起来。

### 二、提问

> 我这半年在定价上想明白了什么？
>
> 我和王磊合作过几次，每次都卡在哪儿？

它读的是已经编译好的 wiki，不是从头翻原料。答得好的问题会**回填成一页新的结论页**——这样你的每一次探索都变成永久的知识，而不是聊完就散。

### 三、体检

> 体检一下

它会找五样东西：两页说法打架的、没人链进来的孤儿页、被反复提到却没有自己那一页的概念、引用了旧版本原料的过期结论、点不开的死链。

**它只报告，不擅自改。** 改哪些、怎么改，你说了算。

体检是手动的。这套系统里没有任何东西会在后台自己跑。

---

## 你改过的东西不会被覆盖

wiki 里的页是机器写的，但你随时可以改。**你改过的段落和措辞会被保留**，下次消化只会往上追加新信息，不会重写整页。

理由很直白：你改那一句，是因为它写错了或者写得不是你的意思。机器第二次把它改回去，等于告诉你「你的修改没用」——而你不会立刻发现，只会某天读到那页时觉得哪里不对。
