# 账本

这本库干过的每一件事都记在这里，只追加，最新的在最下面。

三种记录：`消化` 是吃进了一份原料，`提问` 是回答了一个问题并回填成页，`体检` 是做了一次检查。

**不要手动删除消化行。** 「待提炼」那张清单是拿原料的 UID 到这里比对算出来的——删掉一行，那份原料会重新显示成没消化过，下一次提炼就会把同一份东西再消化一遍，知识层也跟着重一遍。真要让它重新消化，直接说一声就行，不用动这里。

格式：

```markdown
- 2026-08-16 19:33 · 消化 · 定价改版 · UID 20260301091500 · 触及 [[年付定价]]、[[王磊]]
- 2026-08-16 20:10 · 提问 · 「我这半年在定价上想明白了什么」 · 回填 [[年付优先]]
- 2026-08-17 09:02 · 体检 · 2 处矛盾 / 1 个孤儿页 / 3 个缺页概念
```
