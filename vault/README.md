# 欢迎回家

这里是你的笔记库。

现在它还是空的，但 Dataview、Minimal 主题、配色和 CSS 已经布置好了。跟着下面三步，一分钟就能住进来——开荒完成时，项目、人脉、复盘三套系统会一起长出来。

## 三步开荒

**第一步**：Obsidian 打开这个文件夹的时候，会弹出一个窗口问你信不信任。点「信任仓库作者并启用插件」。ziminOS、Dataview 和 Style Settings 会一起启用。

**第二步**：点左下角的齿轮图标，打开设置。在左边那一列往下找，找到 **ziminOS**，点它。

进去以后，顶上有一排标签：**开荒、项目、灵感、复盘、人脉、编辑、文件、边栏**。一个标签就是一套系统，各管各的设置，你现在停在第一张「开荒」上。

**第三步**：点「初始化」按钮。

屏幕右上角冒出「开荒完成 ✅」、放一次礼花，就成了。什么都不用填。

这时候会自动打开这份 README——也就是你现在看的这一篇，往下翻就是日常用法。每天办事的入口是 `90-system/导航`，把它钉在标签页上，以后每天都从它开始。

## 先看一眼最左边那一列

开荒完成后，屏幕最左边那一条竖着的图标栏里，会多出七个 ziminOS 的图标。**鼠标停上去会告诉你它是谁，点一下就直接执行**，不用记快捷键、也不用打字：

| 图标 | 它做什么 |
| --- | --- |
| 一面旗 | 新建项目 |
| 一个灯泡 | 记录灵感 |
| 一本日历 | 打开今天的日记 |
| 一支笔 | 写复盘主题 |
| 一个人带颗心 | 新建人脉 |
| 一份礼物 | 记人情 |
| 一块调色盘 | 打开外观开关 |

这七个是默认摆出来的，判据是「一天里可能按不止一次」。它们下面还有三个灰色的：**切换笔记库、帮助、设置**——Obsidian 1.6 之后把这三个按钮挪进了文件浏览器底下那一条，离文件树太近，想开设置结果常常收起整棵树，所以 ziminOS 把它们请回了这一列（灰色是因为它们做的是 Obsidian 自己的事，不属于这套系统的任何一摊）。ziminOS 一共有三十八条命令，剩下二十八条都在**设置 → ziminOS → 边栏**那一页里，勾一下就出现在这一列，取消勾选就收走。

下面每个动作我都会写「按 `Cmd + P`」那条路——因为三十八条命令都能那么走，而边栏上只摆着你勾过的那几个。两条路通向同一件事，用顺手的那条。

## 中国日历：从时间直接进记录

启用 ziminOS 后，右侧边栏会默认出现一张中国日历。它同时显示公历、农历、节气、传统节日和法定调休：「休」是放假，「班」是周末调休上班。年、季度、月份的标题两边都有自己的前后箭头：找某一年用年箭头，跳三个月用季度箭头，逐月翻用月箭头；无论当前在哪一年、哪种视图，点「今」都会回到月视图并定位当天。

日历上五种时间都能点：点某天打开该日日记，点左边周数打开周复盘，点月份打开月复盘，点季度打开季度复盘，点年份打开年复盘。对应笔记不存在就创建，已经写过就只打开，不会覆盖。

调休日期不需要你维护网站或 API：日历显示或切换年份时会自动校验免费开源的年度数据，24 小时内直接用本地缓存。断网或数据格式有问题时，它保留最后一份正常数据，不会把日历清空。尚未公布的年份会如实显示「待公布」。

## 日常八个动作

### 一、开一个新项目

按 `Cmd + P`（Windows 是 `Ctrl + P`），输入「新建项目」，回车。

它问你三件事：项目叫什么、这个项目跟谁有关、你想把它做成什么样。

跟谁有关那一步有三个选项：**自己做**（只有你，选完直接进下一步）、**和别人一起做**（选一个人，记成同行者）、**客户委托的**（选一个人，记成客户——写下它就等于宣告「我欠他一个交付」）。选了自己做就不会再问你人。

填完，一个项目文件夹就建好了，里面躺着一张项目总览页。

### 一之二、开一个新领域

按 `Cmd + P`，输入「新建领域」，回车。

它只问两件事：领域叫什么、这个领域是什么。填完，`02-areas` 里就多了一个文件夹和一篇总览。

**项目和领域差在哪？看它有没有终点。**「把课讲成一本书」有终点，那是项目；「健康」「手艺」「人脉」没有终点，那是领域。领域不问「这是谁的」——它天然是你自己的。

### 二、写一张卡片

每个项目和领域的文件夹里，都有一篇 `MOC-` 开头的笔记，那是这个项目的总览页——文件名前面那三个字母就是给你认的，它在文件树里永远排在最上面。

在项目总览页里，连打两个左方括号 `[[`，输入卡片的名字，回车。

现在页面上多了一个蓝色的链接。点它。

一张新卡片就长出来了。它会问你「这张卡片讲什么」，用一句话回答就行。

时间、编号、归属，它自己填，你不用管。

### 三、把项目收起来

项目做完了，按 `Cmd + P`，输入「完成项目」，回车。

整个项目文件夹会自己搬进「已归档」，状态改成已完成。

不想做了，用「放弃项目」。只是先放放，用「暂停项目」。

哪天想捡回来，用「重新开始项目」，它会原样搬回来。

### 三之二、把旧库的 MOC 数据库升级一次

如果这本库是从旧版 ziminOS 一路升级上来的，按 `Cmd + P`，输入「升级存量 MOC 数据库」。第一次弹窗只是预览：展开每个文件，可以看到旧代码与新代码的完整差异；没有点「确认升级」之前，一个字都不会改。

它会升级导航页、手动 MOC 模板，以及项目、领域、书籍文件夹里能确认身份的 MOC。旧系统原样生成的数据库会换成相对当前位置的三张表；没有数据库的旧 MOC 会补上；你自己改过的数据库、同一篇里有多个数据库或围栏不完整的文件只列为冲突，原文保持不动。

确认后才批量写入。只要中途一篇写失败，前面已经触达的文件就按倒序恢复；如果你在预览窗口打开期间又改过某篇，升级会停止而不是覆盖新内容。成功后再运行一次，应看到全部已经是新版或没有待升级项。这条命令只为旧库运行一次；以后新建的 MOC 会直接使用新版数据库。

### 四、随手记一条灵感

按 `Cmd + P`（Windows 是 `Ctrl + P`），输入「记录灵感」，回车。

把脑子里刚冒出来的那句话写进去，再回车。它会自动进入 `00-inbox/灵感集.md`，最新一条排在最前面，还会带上今天的日期和时间。灵感集第一行先显示标题，Dataview 从第二行开始展示未完成任务，可以直接勾选；任务组标题会显示这篇灵感集的最后更新时间，下方保留全部历史记录。

想换文件夹、笔记名称、插入位置或记录格式，就到设置 → ziminOS → 灵感那一页改。想真正一键呼出，可以在设置 → 快捷键里搜索「记录灵感」，绑定自己顺手的按键。

### 五、读一本书

按 `Cmd + P`，输入「**读一本书**」，回车。

**你只做两件事：报出书名、从列表里点中是哪一本。** 剩下的它自己做完：

1. 去豆瓣查这本书 → 列出候选（每行带着作者、出版社、出版年，同名书一眼分得清）
2. 你点中一本 → `01-projects` 里长出《书名》文件夹和它的总览页
3. 作者、译者、出版社、出版年、页数、ISBN、豆瓣评分、封面、豆瓣链接——**全部自动填好**，你一个字都不用打
4. 标签也自动打好：豆瓣上大家怎么给这本书分类，它就写成 `#书籍/写作`、`#书籍/方法论` 这样几条
5. 接着它自己去你的设备里找这本书的划线，找到就直接写进总览页的「全部划线」，连章节都归好位

一条命令，两次点击，完事。没有中间文件，不用复制粘贴。

**为什么标签是自动的？** 你现在想到的分类词，和读完这本书的几万人投出来的分类词，不是一回事。后者才能让你书架上的两本书连起来——它们都被打上「方法论」，你才会在标签面板里同时看见。想换个前缀（比如挂到「阅读/书籍」下面）或者只要三条、干脆不要，去设置 → ziminOS → 项目那一页，最底下就是。

**顺带一提，书的 UID 是它的 ISBN。** 别的笔记用时间戳当编号，因为它们没有别的身份；书有——ISBN 是全世界通用的，同一本书在谁的库里都是同一串数字。

**划线从哪来？** 它会自动查这三处，有几处算几处：

| 来源 | 要准备什么 | 能拿到什么 |
| --- | --- | --- |
| 苹果图书 | 什么都不用，本机读过就行 | 划线、批注、**章节** |
| Kindle | 用数据线插上电脑 | 划线、你在设备上写的笔记 |
| 微信读书 | 按一次「连接微信读书」扫码，一辈子一次 | 划线、想法、章节 |

**读到一半又划了新的？** 打开这本书的总览页，按 `Cmd + P` → 「**同步这本书的划线**」。已经在里面的不会重复，新的补进去；你之前写在划线下面的批注一个字都不会动。

**摘成卡片。** 划线是书的，卡片才是你的。在总览页里选中一条值得展开的划线，`Cmd + P` → 「摘成卡片」，给它起个名字。书的文件夹里就长出一张卡片：开头是那条划线的原文，下面空着——那是留给你写「所以呢」的地方。

**一本书读完的标志不是划线多，是摘出了几张卡片。**

读完了？用你已经会的那条「完成项目」把它收起来——**一本书就是一个项目**，同一套流程。

（连不上豆瓣、或者你读的是本机 PDF：用「新建读书笔记」手动建一本，用「导入读书划线」把导出的文字粘进去，这两条老路一直留着。）

## 每天一句话，一年一条主线

### 六、写今天的日记

按 `Cmd + P`，输入「打开今天的日记」，回车。今天那一篇就出来了，没有的话它自己建。**如果这篇日记还没有主题，它会紧接着问你今天主要做什么；写好后再次打开，就只打开日记，不会重复弹窗。**

日记只写两样东西：上半截「今天做了什么」一行一件事，写过程；下半截「今日产出」自动列出你今天新建和改动了哪些笔记，不用管。

**如果今天的主线变了，或者收工前想把早上那句话改得更准，再按 `Cmd + P`，输入「写复盘主题」**。它是明确的修改入口，会带出现有主题，不是另一条「打开日记」命令。

这一句是整套复盘的入口。你只写这一次，剩下的四级全是它的投影：

- 周复盘看七句日主题连起来是什么
- 月复盘看四条周主题连起来是什么
- 一直到年

「打开本周复盘 / 本月 / 本季 / 本年」也都在命令面板里。站在周记上按「写复盘主题」，写的就是周主题——一条命令管五级，它自己认得出你站在哪。

复盘笔记本身是干净的：一个手写小节，加几张自动长好的表，没有一句提示文字。打开它，对着自动表回答下面的问题，一问一段，写完就算复盘完：

- **周复盘**：七天的主题连起来，我这周真正在推进的是什么？哪一天偏离了主线，为什么？下周只改一件事，改什么？
- **月复盘**（看结果，不看过程）：几条周主题连起来，这个月真正完成的是什么？完成的项目里哪一个最值得复盘？下月唯一优先级是什么，为它砍掉什么？
- **季复盘**（看系统，不看事件）：三个月的主线是在推进还是在漂移？完成的项目里有多少是季初就打算做的？下季度做什么、坚决不做什么？
- **年复盘**：十二个月的主题连起来，今年的主线是什么？三大得、三大失各是哪三件，教训各一句？明年主题定什么，它要求我成为什么样的人？

这几个问题不用背，忘了就回这里看一眼。

### 七、把人记下来

按 `Cmd + P`，输入「新建人脉」。它问三件事：他叫什么、多久该跟他说句话（密/近/熟/远）、这段关系往哪个方向使劲。

建好之后，**你再也不用打开这份档案去更新它**。日常发生的事只写一处——当天日记，句子里带上 `[[他的名字]]`。三种写法自动分流到他的档案：

| 你在日记里写 | 它落到哪 |
| --- | --- |
| `- 和 [[张三]] 去了新疆，谈定一起投一家网咖` | 他档案的「关键事件」 |
| `- [ ] 出网咖投资方案给 [[张三]]` | 他档案的「待办」 |
| `- [[张三]]｜去｜送了半斤生普｜两清` | 他档案的「人情账本」 |

最后那种也可以用命令「记人情」四步点选，不用手打。

打开 `02-areas/人脉/MOC-人脉`，四张表自动长好：谁在名录里、该给谁送东西、这个月谁过生日、谁还欠着谁。**「最近联系」是从日记里算出来的，不用你填**——超过该层节奏的会自己标上 ⚠️，那就是该找他的信号。

### 客户 MOC：钱和交付放在一张表里

初始化时，`02-areas/客户/MOC-客户.md`、客户模板与客户目录会和 `MOC-人脉.md` 一起长出来。客户 MOC 只留一张核心表：**人物、金额、交付、创建日期**。待交付的人置顶，其余按累计金额排列；刚建档还没付费的客户显示「—」，不拿 0 假装发生过交易。

先按 `Cmd + P` 运行「新建客户」建档。收了一笔钱，再运行「增加付费」，选客户、产品并填写金额，不用手打格式。写进去的是客户档案「付费与交付」小节里的一行任务：**没打勾＝这笔的东西还欠着，交付完点一下勾**，客户 MOC 会自动刷新。

从旧版升级、库里还没有客户 MOC，或不小心删过它时，运行一次「初始化客户模块」即可补齐；已存在的客户档案与 MOC 一个字都不会被覆盖。

客户答疑继续放在它所属的领域里，不用搬进客户目录。只要这篇答疑同时满足两条：属性区任意字段含该客户的双链（例如 `[[Alex]]`），标签含 `obsidian/QA`，它就会出现在该客户档案的「客户答疑（自动）」表里。正文里普通提到客户不算，避免聊天记录被误收。老客户档案升级后运行一次「补齐客户答疑检索」；新建客户已经自带这块。

### 八、把当前笔记导出成长图或单页 PDF

打开要交付的笔记，按 `Cmd + P`，运行「导出当前笔记」。选择 PNG 或 PDF，再按需填写页眉、页脚和水印；留空就是关闭。三处文本支持 `{title}`、`{date}`、`{time}` 占位符。

导出会按渲染后的全文宽度与高度一次性生成：PNG 是一整张长图，PDF 是只含一页的自定义长页面，不会擅自分页或截掉后半篇。桌面端弹出系统保存位置；环境不支持系统对话框时，文件会回落保存到当前笔记旁边。

## 七个文件夹，各管一摊

| 文件夹 | 放什么 |
| --- | --- |
| `00-inbox` | 收件箱。脑子里冒出来的东西先扔这儿，以后再说。 |
| `01-projects` | 项目。有明确结果、你希望它结束的事。你在读的书也住这儿——读完就是它的终点。 |
| `02-areas` | 领域。要长期照顾、没有终点的事。比如健康、家人、手艺、人脉。 |
| `03-resources` | 资料。你感兴趣的主题，收藏的、查来的东西。 |
| `04-archives` | 已归档。做完的、放弃的、暂停的，都在这儿躺着。 |
| `05-diary` | 日记与复盘。日、周、月、季、年五层，时间轴住这儿。 |
| `90-system` | 系统。导航页和模板住在这里。平时不用进来。 |

前五个加最后一个回答「这东西属于谁」，`05-diary` 回答「这事什么时候发生」。两种问法不是一回事，所以它单独占一格。

一句话记住顺序：**先收进来，再动起来，长期养着，随手查着，做完收起来，天天记着，工具放一边。**

## 九个小提醒

**关于外观**：笔记库默认使用 Minimal 主题和 ziminOS 配色。你可以在设置 → Style Settings 里改颜色；升级 ziminOS 不会把你改过的配色覆盖掉。

看右下角，有个 🎨 按钮。点开是十三个外观片段的开关——文件夹前面的图标、彩虹引导线、代码块行号、当前行高亮、属性栏自动收起、废弃内容突出，都在这里，看着不顺眼随手关掉，立刻生效，不用重启。现在写 `~~不再使用的内容~~`，编辑与阅读时都会显示为弱化文字、淡警示色背景与加粗删除线；若废弃段里还有 `[[双链]]`，它会另带风险底色和边界，目标已经不存在时再升一级红色示警。有两个默认是关着的（代码块横向滚动、水平线中间加图标），想试就打开。

这些开关记的是你的选择，升级 ziminOS 不会替你重新打开你关掉的东西。嫌这个按钮碍眼，可以在设置 → ziminOS → 开荒那一页把它收起来——最左边那列的调色盘图标和命令面板里的「打开外观开关」照样能打开它，三条路通向同一个面板。

**关于字体**：你现在读到的正文就是「霞鹜文楷」（GB 屏幕阅读版），安装时已经连同另外三款阅读字体一起装进了你的电脑：思源宋体 CN（书卷气的衬线）、朱雀仿宋（民国铅字味）、霞鹜新晰黑＋（清爽黑体）。想换口味：设置 → 外观 → 正文字体，下拉里挑一个就行。这是 Obsidian 自己的设置，记的是你的选择，升级 ziminOS 不会替你改回来；字体装在系统里，Word、浏览器这些别的软件也能用。

**关于左边那列图标**：想加想减都在设置 → ziminOS → 边栏那一页，三十八条命令列在那儿，每行左边就是它在边栏上的样子。两件事先说在前面：其一，取消勾选后它在「设置 → 外观 → 功能区」和手机端的边栏菜单里要重启 Obsidian 才彻底消失；其二，反过来，你在 Obsidian 自己那个「功能区」里藏掉的图标，回 ziminOS 这边勾上也不会出现——那是 Obsidian 的开关，得回那儿打开。

**关于文件夹后面那个数字**：左边那棵文件树上，每个文件夹右侧有一个灰色的小数字——那是这个文件夹里攒了多少篇笔记，连它下面的子文件夹一起算。鼠标停在数字上，笔记数和子文件夹数会一起报出来。空文件夹不标数字。

它默认数笔记。但 ziminOS 里的文件夹是**容器**：`01-projects` 里装的是项目，一个项目里装的才是卡片——所以你可能更想让 `01-projects` 后面那个数字回答「我有几个项目」。想那样就去设置 → ziminOS → 文件那一页，把「数什么」改成「文件夹」，或者把「含子文件夹」关掉。整个不想看，把第一个开关关掉，数字当场消失，不用重启。

**关于最近文件和当前路径**：找不回刚才那一篇时，按 `Cmd + P` → 「打开最近文件」，右侧栏会出来一张清单，列着你最近打开过的笔记，点一下就回去。它不会自己占住侧栏，用完关掉就好。清单显示几条、按「打开时间」还是「修改时间」排，都在设置 → ziminOS → 文件那一页。

右下角状态栏还常驻着你此刻这一篇在哪个文件夹里，**点一下就把完整路径复制走**——发给别人、或者写进别的笔记里都省事。不想看，同一页里关掉。

**关于打字时的两件顺手事**：其一，**选中一段文字，直接 `Cmd + V` 粘一条网址，那段文字就变成外链**，不用再手打方括号。它只在你真的选了字、剪贴板里真的是一条带 `https://` 的网址时才动手，其余情况照常粘贴。其二，**每篇笔记记住你上次离开时光标在第几行**，下次打开就回到那里，重启 Obsidian 也还在；但你从一条带标题的双链跳进去时它不插手——那时候你想去的是你刚点的那个位置。两件事都能在设置 → ziminOS → 编辑那一页单独关掉——那一页往下翻就是上面说过的排版九条规则。

**关于大纲和列表**：笔记库里另外装了两个插件，它们不属于 ziminOS，但一起交付给你。**Quiet Outline**（在右侧栏）给长笔记一张能搜索、能折叠的大纲；**Outliner** 让列表变得好使——macOS 按 `Cmd + Shift + ↑/↓`、Windows/Linux 按 `Ctrl + Shift + ↑/↓`，整条会带着子项一起挪；Tab / Shift-Tab 缩进和退回时子项跟着走，需要时还可在 Outliner 设置里打开缩进参考线。两个都可以在设置 → 第三方插件里单独关掉，关掉不影响 ziminOS 的任何功能。

**关于排版**：你写完一篇笔记、切到别的笔记去，ziminOS 会顺手替你把这一篇整理成标准的 Markdown 写法——汉字和英文、数字之间补一个空格，标题、列表、表格、代码块上下各留一个空行，多余的空行收成一行。**它不会在你正打字的那一篇上动手**，所以不用担心打到一半被打断；想当场整理就按 `Cmd + P`，输入「整理当前笔记格式」。

有一件事它绝对不做：动你的双链。`[[MOC-人脉]]` 里面一个空格都不会加，空格只补在方括号外面——链接照样点得动。

九条规则都能单独关掉，路径是设置 → ziminOS → 编辑，往下翻到「排版」那一段。（排版和下面那两件顺手事同住一页，因为它们都发生在你敲字的时候。）不喜欢中文里插空格的，就关掉第一条，其余八条照常。

**关于模板**：如果你想手动套模板，需要打开 Obsidian 的「模板」功能。路径是：设置 → 核心插件 → 找到「模板」→ 打开开关。大多数时候它本来就是开的，你可以先不管这条。

**关于图片**：往笔记里贴图片的时候，旁边会自动冒出一个叫「附件」的文件夹，图片都在里面。这是正常的，别删它。
