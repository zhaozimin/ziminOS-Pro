Fresh Install

全新安装：五步

先装好 Obsidian。到 obsidian.md 下载 1.13.0 或更高版本。已经装了的，打开「设置 → 关于」点「检查更新」。

解压安装包

Windows右键压缩包 →「全部解压缩」→「解压」。

macOS双击压缩包。

一定要解压出来再用。双击压缩包往里点，看到的只是预览，Obsidian 打不开里面的库。

装字体（在打开 Obsidian 之前）

Windows打开「字体」文件夹，按 Ctrl + A 全选，右键 →「安装」。选「安装」，不要选「为所有用户安装」，后者要管理员权限。Windows 11 的右键菜单里没看到，先点「显示更多选项」。

macOS打开「字体」文件夹，逐个双击五个字体文件，在弹出的窗口里点「安装」。

跳过这一步也能用，只是正文不是霞鹜文楷。如果装的时候 Obsidian 开着，装完要完全退出 Obsidian 再打开，因为它只在启动时读一次系统字体。

把笔记库放到长期住的地方，改个名字

把「ziminOS」这个文件夹整个拖到你打算长期存放的位置，比如 D 盘，或者「文档」里。然后改成你喜欢的名字：这个名字就是你这套系统的名字。

别把它留在「下载」里，那里迟早会被清理。也别只拖文件夹里面的东西：里面藏着 .obsidian，只拖看得见的那一个文件，等于只搬了一半。

用 Obsidian 打开它

打开 Obsidian，在「打开本地仓库」那一行点「打开」，选中刚才那个文件夹。如果 Obsidian 已经开着别的库：点左下角的库名 →「管理仓库…」，就回到这个界面。

第一次打开会问「你是否信任这个仓库的作者？」，点「信任仓库作者并启用插件」。

英文界面上这两处是 Open folder as vault 与 Trust author and enable plugins。

点一次初始化

点左下角的齿轮打开设置，在左边那一列往下找到 ziminOS。顶上第一张标签「开荒」里，点「初始化」。

屏幕上出现「开荒完成 ✅」、放一次礼花，就成了。它会自动打开库里的 README，日常怎么用都写在那一篇里。

Check

装好了吗？看这五处

  • 最左边那一列多出 ziminOS 的图标（新建项目、记录灵感、今天的日记……），鼠标停上去会告诉你它是谁。
  • 右侧栏有一张中国日历，显示农历、节气和法定休/班。
  • 右下角有一个 🎨 按钮，点开是外观片段的开关。
  • 正文是霞鹜文楷：「设置 → 外观 → 正文字体」里写着 LXGW WenKai GB Screen。
  • 「设置 → 第三方插件」的「已安装插件」里，ziminOS 的版本号和安装包文件名里的一样。
装完之后解压出来的其余东西（字体、升级文件、许可证、这份说明）都可以删掉。以后升级时下载新的安装包就行。
Upgrade

以后怎么升级

升级只换程序，绝不整份覆盖。不要把新包里的「ziminOS」文件夹复制到你原来的库上，也不要替换整个 .obsidian。你在设置里做过的每个决定、左边摆好的图标、微信读书的登录，都存在那里面，盖掉就找不回来了。你写的笔记不在程序文件里，升级碰不到它们。

下面每一步都守一条规则：只拖文件，不拖文件夹。macOS 上把一个文件夹拖到同名文件夹上选「替换」，会把目标整个换掉，连同里面你自己的设置；拖文件只替换同名的那几个。

下载新版安装包并解压

和第一次一样。新包里的「ziminOS」这回用不到，别打开它，你的笔记在你原来那本库里。

换 ziminOS 程序（每次都做）

在 Obsidian 里打开你原来那本库 →「设置 → 第三方插件」，点「已安装插件」右边的文件夹图标（鼠标停上去显示「打开插件文件夹」）。

再打开新包里的「升级文件 → 插件文件夹 → ziminos」，选中里面的四个文件：main.js、manifest.json、styles.css、ziminOS-Eagle-Bridge.eagleplugin，拖进刚才打开的那个文件夹里的 ziminos 文件夹，选「替换」。

换外观片段（每次一起做）

「设置 → 外观」，在「CSS 样式代码片段」那一行点文件夹图标（「打开样式代码片段文件夹」）。把新包「升级文件 → 样式代码片段文件夹」里的全部 .css 文件拖进去，选「替换」。你自己放进去的片段名字不一样，不会被碰到。

这一版新出现的片段默认是关着的，想用就点右下角 🎨 打开。你以前关掉的片段，替换之后照样关着。

另外四个插件与主题（一般不用动）

它们锁着版本，很少变；哪一版变了，发行说明会写。到时办法相同：「升级文件 → 插件文件夹」里的 dataview、obsidian-outliner、obsidian-quiet-outline、obsidian-style-settings 各自点进去全选文件，拖进插件文件夹里同名的那个文件夹；「升级文件 → 主题文件夹 → Minimal」里的文件，拖进「设置 → 外观」里「打开主题文件夹」进去的那个 Minimal。

升级文件里一份设置文件都没有，所以照着拖，不会盖掉你调过的配色与插件设置。

完全退出 Obsidian，再打开

Windows点窗口右上角关闭。macOS按 Cmd + Q。

重新打开后，「设置 → 第三方插件」里 ziminOS 的版本号应当是新包文件名里的那个。不要再点「初始化」——你的库早就开过荒了。

这次更新带了新字体？照全新安装的第二步装上，再完全退出 Obsidian 重开。「重新加载」不够，Obsidian 只在启动时读一次系统字体。
Troubleshooting

常见问题

现象多半是因为怎么办
Obsidian 打不开那个文件夹还在压缩包里，没有真的解压出来先解压，再打开解压出来的那一份
没问「是否信任」，左边也没有 ziminOS 的图标点成了「在安全模式中打开该仓库」「设置 → 第三方插件」关掉「安全模式」，再在「已安装插件」里把 ziminOS、Dataview、Style Settings、Outliner、Quiet Outline 的开关打开
点「初始化」提示「检测到已有笔记，ziminOS 只在空库开荒」这本库里已经有别的笔记，比如把包里的东西拷进了你原来的库用包里那本全新的「ziminOS」单独开一本，不要和已有笔记的库混在一起
正文不是霞鹜文楷字体没装上，或者装的时候 Obsidian 开着装好字体后完全退出 Obsidian 再打开；「重新加载」不够
Windows 右键里没有「安装」选中的东西里混进了文件夹或别的文件；或者 Windows 11 把它收进了二级菜单只选字体文件；Windows 11 先点「显示更多选项」；也可以双击字体文件，在预览窗口里点「安装」
