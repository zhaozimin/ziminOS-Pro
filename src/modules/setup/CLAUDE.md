# src/modules/setup/

> L2 | 父级: ../../CLAUDE.md

开荒模块。它在 V2 从 projects 里独立出来，因为开荒横跨全库骨架并要收齐三个模块的诉求——住在其中任何一个模块下面，都是让物理位置对读者说谎。

## 成员清单

init.ts: 开荒编排，由设置页按钮与 init-vault 命令唯一触发。它只保证两件事属于笔记库本身：PARA 骨架目录，以及「开荒过没有」这个事实。其余产物一律由各功能模块自报 VaultSeed，main 装配后递进来——因此本文件不 import 任何兄弟模块，加一个模块只需在 main 多传一个 seed，这里一行不改。另导出 applySeed 供客户模块的按需开荒复用，让「开荒时长出」与「按需长出」是同一段代码的两个触发点，而不是两份各自演化的实现。开荒收尾把学员送到 README 而非导航（v0.10.1）：README 头部是作者名片、正文是说明书，刚开完荒的人需要的是说明书；日常入口仍是导航。只拿到 main.js 的库没有 README，回落导航。

celebrate.ts: 开荒成功后的收尾表情——从左右两侧向中间对喷一次礼花，几秒后连同整层自行移除。它是 v0.19.0 用来**取代那个弹窗**的：从前 projects 的 finish 会在这一刻弹出输入框问用户的名字、替他开第一个项目，而那恰恰是他刚点完「初始化」、正等着看结果的一瞬间——一个凭空出现、还向他索取的弹窗，把「装好了」变成了「怎么又要我填」。礼花同样是告诉他成了，但不索取、不阻塞、不需要他做任何决定。三条纪律都是「动画」这件事特有的：**必须能自己收场**（清理同时挂在动画完成与 plugin.register 上，前者管正常路径、后者管「还没跑完就禁用了插件」，一次性动画留下的节点不会有人报错，只会越积越多直到用户觉得 Obsidian 变卡却查不出原因）、**尊重系统的减少动效偏好**（那是无障碍设置不是审美设置，开着它的人多半前庭功能敏感，满屏飞行的粒子对他不是庆祝是不适）、**绝不吃鼠标**（覆盖层铺满整个视口，不设 pointer-events: none 就会让礼花飞的那两秒里点什么都没反应，而用户不会把这归咎于一个动画）。定位取 fixed 而不是 absolute：absolute 的 inset: 0 要靠「宿主恰好是个定位祖先」才成立，而那是别人家 DOM 的实现细节，赌错的表现是整层贴到别的元素上、礼花在屏幕角落里飞。轨迹逐片随机算在 TS 里、只有「一片纸屑长什么样」在 CSS 里：七十二片各有各的落点，写成关键帧要生成七十二组，那是把随机性硬编码。
schemaNote.ts: 属性类型示例笔记的纯文本工厂，与 `.obsidian/types.json` 共同组成属性契约的机器相与人类可读相；示例刻意使用视图不认识的 type，避免它污染任何业务名录。

## 模块契约

首次开荒与后续补齐走同一条流程，差别只有两处：空库检查，以及 initializedAt 只在首次确定性种子落齐后写一次。首次检查会排除已生成的种子路径，因此中途失败不会让插件自己的半成品反过来封死恢复入口。（v0.19.0 之前还有第三处「各模块的 finish」，见下。）补齐时重写首次时间等于让面板向学员陈述一件关于他笔记库历史的假事，故严格禁止。

VaultSeed 是本模块认识的唯一形态，v0.19.0 起只有 folders 与 notes 两个字段。此前还有第三个可选的 finish，为的是让「开出第一个项目」这类只该在首次发生的动作归属提出诉求的那个模块而不是开荒本身——形状是对的，但它唯一的实现者（projects 那个问名字的弹窗）被删掉之后，留着就是一份没有实现的契约。**扩展点的价值不在于它可能有人用，而在于它现在有人用**；等真需要时按同样的形状加回来，比让读者对着一个空钩子猜它为谁而设更诚实。

收尾表情因此从「各模块自己的 finish」收敛成开荒自己放的一次礼花：它不属于任何一个提诉求的模块，它属于「开荒成功了」这件事本身。

第七个根文件夹 05-diary 不在 INIT_FOLDERS 里，人脉目录也不在。它们由复盘与人脉模块各自带来：「这个目录存在，是因为那个模块存在」这件事必须在代码里也成立，否则删掉一个模块，库里会留下一个永远空着的目录。
