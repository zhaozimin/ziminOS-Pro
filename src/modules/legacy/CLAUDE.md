# modules/legacy/

> L2 | 父级: ../../CLAUDE.md

旧版入口模块。它把 Obsidian 1.6 挪走的三个按钮——**切换笔记库、帮助、设置**——注册成三条 ziminOS 命令，于是它们回到最左边那一列，也进命令面板、也能绑快捷键。

它是全仓库**第二处、也是唯一另一处**接触 Obsidian 非公开成员的地方（第一处是 appearance/snippets.ts 里那次 `customCss`）。这次借用由用户在 v0.17.0 明确授权，备案写在 L1 的第 8 条，理由与第一处同源：不碰，这件事就不成为一个功能。

## 为什么不是别的做法

**为什么不打包上游插件。** `Quorafind/Obsidian-Legacy-Vault-Switcher` 做的正是这件事，但它**没有许可证**——没有许可证等于保留一切权利，转发它不合法。这条判据把「打包交付」这个选项直接排除，与 Outliner / Quiet Outline（都是 MIT）的处置完全不同。

**为什么不用 CSS 挪。** 1.6 之后那一条是 `.workspace-sidedock-vault-profile`，它住在左侧栏内部；CSS 挪不动一个元素的父节点，也造不出 Obsidian 已经删掉的按钮。Minimal 自带的 `vault-profile-top` 只能把它移到文件浏览器顶部，那不是「旧版的位置」。

**为什么不复刻一条按钮栏。** 复刻要么写死像素定位，要么往 Obsidian 自己的 DOM 里塞节点——MySnippets 就是这么散架的（见 appearance 的 L2）。走命令注册台则一分钱不花地拿到四样东西：命令面板里搜得到、快捷键绑得上、「设置 → ziminOS → 边栏」那张清单里勾得掉、摆出来之后位置归用户拖。

## 成员清单

vaultDock.ts: 三条命令，一处模块增强，两个纯函数。模块增强把 `app.setting?.open`、`app.openVaultChooser`、`app.openHelp` 声明成**可选**成员——`obsidian.d.ts`（1.13.1）里 App 的公开成员只有十项，这三件事一件都不在其中，而声明成可选意味着 TypeScript 强制每一处先判空。`bind` 负责验形并把宿主绑回去（摘下来直接调会丢 `this`，那种错不报错、只是点了没反应）；`run` 负责「能调就调，探不到就弹一句人话」。三条纪律与第一处缺口逐条对齐：只借「点下去要发生什么」这一步、运行时验形且探不到只降级不抛异常、声明与调用同处一个文件。

## 一处与预案不同的落地，记在这里

装配时的预案是「探不到就不画那一枚按钮」。实际做的是**照常注册、点下去说明白**——因为 CommandRegistry 有一条更硬的纪律：命令必须在任何情况下都可见可点，用户在做不到时该得到一句「为什么」，而不是眼看着命令凭空消失（一个会自己隐身的图标比一句提示更让人困惑）。两种都是降级，后者与这个仓库其余命令的行为一致，因此选了后者。

## 与外部的接线

对上只暴露 `registerLegacyDock(ctx)`，不交回任何同步函数——它没画任何自己的东西，那三枚图标是 ribbon 模块照花名册摆的。

它也**没有**自己的设置页，判据是「一个控件撑一整页是把分页做成摆设」的反面：整个模块只有「摆不摆出来」这一个问题，而那正是「边栏」页早已在回答的问题。三条命令自动出现在那张清单的最后一组「旧版」里，着中性灰——它们做的是 Obsidian 自己的事，不属于 ziminOS 的任何一摊，颜色把这句话说了出来。它们同时进 `DEFAULT_RIBBON_COMMANDS`：一个需要先去设置页勾选才回来的按钮，等于没有回来。

删掉这个模块，红线重新完整，库里一个字节不变。
